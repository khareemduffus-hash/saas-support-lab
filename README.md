# SaaS Customer Support Lab

## Overview
This project simulates a real-world SaaS customer support environment using Freshdesk. It demonstrates handling support tickets, troubleshooting issues, escalating bugs, and using AI tools to improve efficiency.

## Tools Used
- Freshdesk (ticketing system)
- ChatGPT (AI-assisted support responses)

## Key Skills Demonstrated
- Ticket management and prioritization
- Customer communication and de-escalation
- Technical troubleshooting (login, UI, billing issues)
- Escalation to engineering teams
- Knowledge base creation
- AI-assisted workflows

## Ticket Scenarios
- Forgot Password
- Billing discrepancies 
- Bug escalation (dashboard failure)
- Adding a New Client
- Security concern (suspicious login) - Escalation
- Multi-issue ticket handling

## AI Workflow Example
Used ChatGPT to draft responses and troubleshoot issues efficiently.

Example prompt:
"Act as a SaaS support specialist. Draft a professional response to a login issue including troubleshooting steps."

## Outcomes
- Resolved 5+ simulated tickets
- Created knowledge base articles for common issues
- Practiced escalation workflows with structured documentation
